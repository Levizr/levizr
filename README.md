## About

Levizr Technologies is a tech innovation company building powerful, lightweight developer tools.

Our flagship project is **Morph** — write HTML, CSS, and JS (`.mx` + JSX + TypeScript), ship a native OpenGL binary. No browser. No Electron. No WebView.

Hello-world in **162KB**, self-contained.

## Flagship: Morph

> Build native OpenGL applications with HTML, CSS, and JavaScript.

- **Compiler, not interpreter:** `.mx` → Rust (Oxc + IR) → C++ → native binary
- **Web DX, native output:** JSX, `morphState`, `fetch()`, Tailwind, Flexbox, animations, DevTools (F12)
- **Dev mode:** `morph dev` — hot reload over loopback, no restart
- **Build mode:** `morph build --static` — tiny distributable binary

```bash
curl -fsSL https://morph.levizr.com/install.sh | sh
morph new my-app && cd my-app && morph install && morph dev
```
